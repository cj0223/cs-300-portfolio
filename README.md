# cs-300-portfolio
CS 300
This repository contains my portfolio artifacts for CS 300: DSA – Analysis and Design.
For this course, I selected one component from each project to demonstrate my understanding of data structures, algorithms, run‑time analysis, and program design.

Project One — Runtime & Memory Analysis
This document analyzes the performance characteristics of three data structures:

Vector

Hash Table

Binary Search Tree

It includes pseudocode, Big‑O analysis, memory considerations, advantages/disadvantages, and a final recommendation based on advisor requirements.

Project Two — Course Sorting Program
This C++ program loads course data, stores it in a vector, sorts the courses alphanumerically, and prints the full list.
File included: VectorSorting.cpp

What problem was I solving in these projects?
Both projects focused on understanding how different data structures behave and how those behaviors impact program performance. Project One required analyzing run‑time and memory usage for vectors, hash tables, and binary search trees. Project Two required implementing a sorting program that outputs Computer Science courses in alphanumeric order.

How did I approach the problem?
I approached each project by identifying the operations required—loading data, searching, inserting, and sorting—and then selecting the most appropriate data structure based on efficiency. Understanding data structures is essential because choosing the wrong one can make a program slow, memory‑heavy, or difficult to maintain.

How did I overcome roadblocks?
Most challenges came from debugging logic errors and ensuring the sorting algorithm handled all course formats correctly. I overcame these issues by breaking the problem into smaller steps, using targeted print statements, reviewing pseudocode, and revisiting course materials when needed.
